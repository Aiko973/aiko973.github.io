Pour remplacer une image : garder le meme nom de fichier, rien d'autre a
faire. Pour changer de nom ou d'extension, mettre a jour "cover" / "media"
(projets) ou "profile.photo" (page a propos) dans assets/js/content.js.

Une image manquante n'affiche pas d'erreur : la carte retombe sur une tuile
de repli.
